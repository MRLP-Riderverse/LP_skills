# Local youth-culture recon worksheet

## Candidate ledger

For each candidate, record:

- Title and canonical URL
- Publication date and outlet
- Reference date and cutoff window
- Place/community
- Youth status: youth-led / youth-adjacent emerging / general local scene
- Source-supported human signal: quote, project, venue, gathering, practice, or identity crossing
- Anti-isolation interpretation (clearly marked as analysis)
- Verification route: source page, exact-title search, or secondary index
- Any limitation: snippet-only, paywall, blocked page, or incomplete extraction

## Search sequence

1. Search by place + scene terms: `Toronto DIY music youth interview 2026`, `Montreal artist collective`, `Ottawa bilingual hip-hop festival`, `Vancouver youth makers`, etc.
2. Search independent/campus/local outlets directly with `site:` queries.
3. Search exact titles again to confirm date and canonical URL.
4. Prefer profiles and interviews over listicles; use a listicle only when it contains concrete local detail and label it as discovery coverage.
5. Stop at three to five strong items rather than padding the set.

## Date-window rule

Compute the cutoff from the user’s stated reference date, not from the machine’s current date. Put older but useful items in a clearly labeled “near-match” section. Never call a result “recent” without displaying its date.

## Verification fallback

If full-page extraction is unavailable, do not pretend to have read the article. Use only claims explicitly present in search metadata, verify the URL/date through an exact-title result, and state that the page could not be fully extracted. If a claim matters and cannot be supported by the available evidence, omit it.
