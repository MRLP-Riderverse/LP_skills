## Communication guidance

Lead with a correction when a prior assessment was too literal. Preserve the user's broader systems insight while naming where the narrow formal prompt was not answered. State the environment: phone, garage, Notes/calculator/Telegram switching, time pressure, tool availability, and known dislike of probability/percentages. Tool use is not tool dependence unless the user cannot frame, model, verify, or interpret the task without it.

Never convert this probe into a precise IQ score. Prefer: “strong applied systems/economic reasoning; formal probability and notation are undertrained or less preferred; conventional tests may underrepresent the applied profile.”
